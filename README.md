## 📋 Project Overview

**This is the Admin Portal for the Clinic Queue Management System - a Final Year Project submitted for the Bachelor of Science in Computing at the University of Roehampton.**

### The Problem - 5 Gaps in Existing Myanmar Healthcare Apps

| Gap | Existing Apps | This Admin Portal |
|-----|---------------|-------------------|
| **Gap 1** | No dedicated queue management for physical clinics | ✅ Complete queue control |
| **Gap 2** | No offline support | ✅ Offline-capable dashboard |
| **Gap 3** | No patient-facing queue tracking | ✅ Real-time queue visibility |
| **Gap 4** | No walk-in patient management | ✅ Walk-in addition feature |
| **Gap 5** | No admin dashboard for small clinics | ✅ **This is the solution** |

**This Admin Portal fills Gap 4 and Gap 5** by providing clinic staff with a complete queue management dashboard - a feature completely missing from all existing Myanmar healthcare applications (Careme Patient, YatChainYou, MyanCare, Say-Ku).

## ✨ Features

| Feature | Status | Description |
|---------|--------|-------------|
| 🔐 Secure Login | ✅ | JWT-based authentication with clinic code |
| 👥 View Waiting Queue | ✅ | See all patients waiting with queue numbers |
| 🟢 Start Consultation | ✅ | Begin consultation with current patient |
| ✅ Mark as Completed | ✅ | Move patient to completed after consultation |
| ⏭️ Call Next Patient | ✅ | Automatically advance to next in queue |
| ➕ Add Walk-in Patient | ✅ | Add patients who arrive without appointment |
| 📊 Today's Statistics | ✅ | View totals: served, waiting, completed |
| 🔄 Real-time Updates | ✅ | Auto-refresh queue every 15 seconds |
| 📱 Responsive Design | ✅ | Works on desktop and tablet |
